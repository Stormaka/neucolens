Sinh viên TƯ DUY như thế nào? (phân tích git history)
25 điểm

⭐ Novelty — Criterion 3.4 (Debugging Strategy)

Tiêu chí duy nhất được đánh giá từ git revision history thay vì submission cuối cùng — phân tích commit messages, atomic commits, pattern debug. Chưa có hệ thống nào trên thế giới làm điều này bằng LLM ở quy mô lớn.

⚠️ WARNING
Fat Server / God File
server.js (424 dòng) chứa database helpers + route handlers + business logic. Nên tách thành controllers/ + services/ + models/.
⚠️ WARNING
Missing Auth Guard
JWT token tạo ra nhưng không verify ở các request sau. Endpoint /review có thể bị gọi bởi bất kỳ ai.
ℹ️ INFO
File-Based Database
JSON file (projects.json) không concurrent-safe. Ổn cho demo KLTN, không phù hợp production. Recommend: SQLite.
